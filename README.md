# zjCanvas
This is a website for zj portfolio website.

Content (reels, posters, logos, carousels, brochures, testimonials, tools, contact email, social links, hero stats) is editable at `/admin` — see [DEPLOYMENT.md](DEPLOYMENT.md) for setup and the admin server in `server/`.

## Local development
```bash
cd server
npm install
npm start
```
Then open `http://localhost:3000` for the site and `http://localhost:3000/admin` for the admin panel. The first run prints a generated admin password once in the terminal.
